# /survival-kit:off-work — 퇴근 카운트다운

입력: $ARGUMENTS

## 절차

1. 퇴근 시각을 정한다. 입력이 비어 있으면 18:00이다. 입력에 시각이 있으면 24시간제 HH:MM으로 바꿔 쓴다(예: "7시 반" → 19:30, "17" → 17:00). 시각으로 읽을 수 없으면 18:00을 쓴다.
2. 현재 시각을 셸 명령으로 읽는다. 시각을 추측하지 않는다.
   - Bash 도구가 있으면: `date +%H:%M`
   - PowerShell 도구만 있으면: `Get-Date -Format HH:mm`
3. 퇴근 시각에서 현재 시각을 빼 남은 시간을 분 단위로 계산한다.

## 출력 형식

한 줄만 출력한다.

- 남았을 때: `퇴근까지 2시간 35분 남았습니다. (지금 15:25 · 퇴근 18:00)`
  - 1시간 미만이면 `35분`, 정각 단위면 `2시간`처럼 0인 단위는 쓰지 않는다.
- 같을 때: `지금 퇴근 시각입니다. (18:00)`
- 지났을 때: `퇴근 시각이 25분 지났습니다. (지금 18:25 · 퇴근 18:00)`
