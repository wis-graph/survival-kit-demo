# /survival-kit:morning-news — 아침 뉴스 세 줄 브리핑

입력: $ARGUMENTS

## 절차

1. 관심 분야를 정한다. 입력이 비어 있으면 **AI, 경제, 비영리** 세 분야를 쓴다. 입력에 분야가 적혀 있으면 그 분야들을 쓴다.
2. 분야마다 수집 기간을 정한다. 환경 정보의 오늘 날짜가 기준이고, 날짜는 YYYY-MM-DD로 적는다.
   - 기본: 어제와 오늘, 이틀 (예: 2026-10-03 ~ 2026-10-04)
   - **비영리**: 기사가 적은 분야라 오늘을 포함한 최근 7일 (예: 2026-09-28 ~ 2026-10-04)
3. 분야마다 서브에이전트 하나씩, **한 메시지 안에서 Agent 도구를 분야 수만큼 동시에 호출**한다. 하나씩 차례로 띄우지 않는다. 각 호출은 `subagent_type: general-purpose`, `model: sonnet`으로 하고, 아래 "수집 지시문"의 `{분야}`와 그 분야의 `{기간}`을 채워서 프롬프트로 넘긴다.
4. 서브에이전트 결과가 모두 오면 분야마다 후보 중 가장 중요한 기사 하나를 고른다. 고르는 기준은 영향 범위가 넓은 것, 후속 보도가 이어질 것, 여러 매체가 다룬 것 순이다.
5. 아래 "출력 형식"대로 브리핑을 쓴다.

## 수집 지시문 (서브에이전트 프롬프트)

```
{분야} 분야에서 {기간}에 발행된 뉴스를 찾아라.
- 먼저 해당 분야의 뉴스 섹션 페이지(예: 연합뉴스·Reuters·AP 등의 {분야} 섹션, 분야 전문 매체의 최신 기사 목록)를 WebFetch로 2곳 이상 열어, 발행 시각이 적힌 최신 기사 목록에서 후보를 고른다.
- 이어서 WebSearch로 한국어와 영어 검색을 한다. 검색어에 날짜 문자열을 넣지 말고, 분야 핵심어와 "오늘", "latest", "this week" 같은 말을 쓴다.
- 후보 기사는 WebFetch로 열어 발행일을 확인한다. 발행일이 {기간} 안인 기사만 남기고, 끝내 확인되지 않는 기사는 버린다.
- 같은 사건을 다룬 기사는 하나로 합치고, 가장 원문에 가까운 기사의 링크를 남긴다.
- 최대 3건을 아래 형식으로만 돌려준다. 실제로 연 적 있는 URL만 쓰고, URL을 지어내지 않는다.

1. 제목: …
   매체: …
   발행일: YYYY-MM-DD
   URL: https://…
   요약: 무슨 일이 있었고 왜 중요한지 한국어 한 문장

섹션 페이지 2곳과 기사 페이지 5개 이상을 열어 보고도 기간 안의 기사를 찾지 못했을 때만 "없음" 한 단어를 돌려준다.
```

## 출력 형식

제목 한 줄과 분야당 한 줄만 출력한다. 분야가 셋이면 세 줄이다. 브리핑 뒤에 다른 후보, 고른 이유, 수집 과정 설명을 덧붙이지 않는다.

**아침 뉴스 · YYYY-MM-DD**

- **AI** — 무슨 일이 있었고 왜 중요한지 한 문장. ([매체](URL), MM-DD)
- **경제** — … ([매체](URL), MM-DD)
- **비영리** — … ([매체](URL), MM-DD)

- 링크는 서브에이전트가 돌려준 URL만 쓴다. 서브에이전트 결과에 없는 URL을 새로 쓰지 않는다.
- 서브에이전트가 돌려준 기사라도 발행일이 수집 기간 밖이면 버린다.
- 한 줄은 60자 안팎으로 쓰고, 숫자(금액·비율·날짜)가 있으면 넣는다.
- 서브에이전트가 "없음"을 돌려준 분야는 "**경제** — 최근 이틀 사이 눈에 띄는 기사가 없습니다."처럼 쓴다. 비영리는 "최근 일주일 사이"로 쓴다.
